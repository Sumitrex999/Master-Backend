#Postman (isClient : like Browser) - to send req to the server.
req.params - here params is the dynamic value of the req API.

#Methods:
Delete - params: delete by id.
put- update the entire data or created a new data(complete update).
patch - update the existing data (partial update).

#Status Code 
204 - delete req success, does n't display the message or response in postman.
201 - create req success.
200 - any req success.
